Privacy, plainly.

This page explains how this website handles information. It applies to the Minerva Studio website only.

Last updated
October 4, 2026

What this website collects

This is a static website. It has no accounts, contact form, analytics script, or advertising tracker. We do not set cookies or store personal information in your browser through this website.

Hosting data

This site is prepared for GitHub Pages hosting. GitHub states that it logs and stores visitors’ IP addresses for security when a GitHub Pages site is visited. GitHub handles that information under its own privacy statement. You can read more in GitHub’s Pages documentation.

Links and messages

If you follow a link to another website, that site’s own privacy terms apply. If you choose to email us through a support address, your message and email address will be used to respond to you.

About NextPeriod

This notice covers this website only. It does not describe how the NextPeriod app handles information. For questions about the app, please contact Minerva Studio.

Questions or changes

For privacy questions, see our Support page. If we add forms, analytics, or other services to this website, we will update this page to explain them.
